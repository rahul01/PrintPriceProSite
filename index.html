Electricity Cost = (Printer Power in Watts / 1000) × Print Time in hours × Electricity Rate per kWh
Labor Cost: ₹0.00
Labor Cost = (Labor Time in minutes / 60) × Labor Rate per hour
Machine Cost: ₹0.00
Machine Cost = Machine Cost per hour × Print Time in hours
Hardware Cost: ₹0.00
Hardware Cost = User-entered per-job cost (screws, inserts, etc.)
Overhead: ₹0.00
Overhead = Direct Costs × (Overhead % / 100)
Subtotal: ₹0.00
Subtotal = Direct Costs + Overhead
Markup: ₹0.00
Markup = (Subtotal − Hardware share) × (Markup % / 100) + Hardware share × (Hardware Markup % / 100)
Hardware share = Hardware × (1 + Overhead % / 100); blank Hardware Markup % = Markup %
Shipping Cost: ₹0.00
Shipping Cost = User-entered per-job cost (added after Overhead and Markup, not marked up)
Packaging Cost: ₹0.00
Packaging Cost = User-entered per-job cost (added after Overhead and Markup, not marked up)
Price Before GST: ₹0.00
Price Before GST = Subtotal + Markup + Shipping + Packaging
GST: ₹0.00
GST = Price Before GST × (GST % / 100)
Final Price: ₹0.00
Final Price = Price Before GST + GST
